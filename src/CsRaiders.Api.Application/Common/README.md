# Common

## Overview
Houses common contracts, timing abstractions, database context abstractions, repository interfaces, security service contracts, and shared data transfer models utilized across the Application layer.

## Subdirectories & Boundaries
- Abstractions: [./Abstractions/README.md](./Abstractions/README.md) - Core platform timing and session cookie writing abstractions.
- Interfaces: [./Interfaces/README.md](./Interfaces/README.md) - Primary database context abstractions, transaction scopes, repository specifications, and security services.
- Models: [./Models/README.md](./Models/README.md) - Shared DTOs, query filter models, projection summaries, and operation result wrappers.
