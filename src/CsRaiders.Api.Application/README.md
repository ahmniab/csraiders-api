# Application

## Overview
Represents the core Application layer of the CsRaiders API, encapsulating business contracts, persistence repository abstractions, data transfer models, and dependency injection configuration.

## Subdirectories & Boundaries
- DependencyInjection: [./DependencyInjection/README.md](./DependencyInjection/README.md) - Service registration and dependency container extensions for the Application layer.
- Common: [./Common/README.md](./Common/README.md) - Shared application contracts, database context and repository interfaces, and data transfer models.
