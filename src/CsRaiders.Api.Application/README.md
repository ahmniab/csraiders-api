# Application

## Overview
Represents the core Application layer of the CsRaiders API, encapsulating business contracts, persistence repository abstractions, data transfer models, feature use case handlers, and dependency injection configuration.

## Subdirectories & Boundaries
- Common: [./Common/README.md](./Common/README.md) - Shared application contracts, timing abstractions, database context and repository interfaces, and data transfer models.
- DependencyInjection: [./DependencyInjection/README.md](./DependencyInjection/README.md) - Service registration, mediator pipeline behaviors, and dependency container extensions for the Application layer.
- Features: [./Features/README.md](./Features/README.md) - Vertical slice business feature implementations for administration, authentication, and session management.
