# Features

## Overview
Organizes application-level business use cases into vertical feature slices covering administration, authentication, and session lifecycle management.

## Subdirectories & Boundaries
- Admin: [./Admin/README.md](./Admin/README.md) - Role-based access control, permission overrides, and user account lifecycle administration.
- Auth: [./Auth/README.md](./Auth/README.md) - Authentication commands including login, registration, OTP validation, and password recovery.
- Sessions: [./Sessions/README.md](./Sessions/README.md) - User session management, revocation, logout, and active session querying.
